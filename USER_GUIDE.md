## Getting Started

### What is Calm Commander?

Calm Commander is a task management app specifically designed for AuDHD (Autism + ADHD) brains. Unlike traditional to-do apps, it:

- **Tracks your daily energy capacity** (spoons) based on how you're actually feeling
- **Prevents burnout** with built-in override limits and accountability
- **Adapts to crisis mode** when you're overwhelmed
- **Auto-estimates task effort** so you don't have to guess
- **Forces external accountability** before letting you overcommit

### First Time Setup

1. **Open the app** in your browser
2. You'll see the main interface with:
   - Coach Mode / Crisis Mode toggle at top
   - "Start Daily Neuro-Check" button
   - Task views (Today, This Week, etc.)
3. **Start with a Neuro-Check** (see next section)

## Daily Neuro-Check

**Why:** Your brain doesn't have the same capacity every day. The Neuro-Check calculates your realistic spoon capacity based on sleep, mood, burnout indicators, and brain mode.

### How to Do Your Daily Neuro-Check

1. **Click "Start Daily Neuro-Check"** (appears at the top when you haven't done one today)

2. **Answer the questions honestly:**

   **Mood Level (1-5):**
   - 1 = Terrible (very low mood)
   - 3 = Okay (neutral)
   - 5 = Great (high mood)

   **Sleep Quality (1-5):**
   - 1 = Barely slept
   - 3 = Okay rest
   - 5 = Excellent sleep

   **Energy Units (1-5):**
   - How many batteries do you have today?
   - 1 = Running on empty
   - 5 = Fully charged

   **Brain Mode:**
   - ADHD Mode = Scattered, need variety
   - Autism Mode = Need routine, predictability
   - Balanced = Mix of both today

   **Burnout Indicators (check all that apply):**
   - [ ] Sleep disrupted
   - [ ] Executive dysfunction
   - [ ] Sensory overwhelm
   - [ ] Social exhaustion
   - [ ] Increased meltdowns/shutdowns
   - [ ] Physical symptoms
   - [ ] Lost interest in things

3. **Click "Calculate My Spoons"**

4. **You'll see:**
   - Your spoon capacity for the day (e.g., "🥄 5 spoons")
   - This appears at the top of the screen
   - Tasks will now show how many spoons they cost

### What Your Spoon Count Means

- **5+ spoons** = Good capacity day, can take on normal workload
- **3-4 spoons** = Moderate capacity, be selective with tasks
- **1-2 spoons** = Low capacity, only essentials
- **0 spoons** = Survival mode, delegate/defer everything possible

### Quick Spoon Boosters

After your Neuro-Check, you'll see 6 quick boosters you can use **once per day**:

- **Water** (8oz+) → +1 spoon
- **Protein snack** → +1 spoon
- **5min movement** → +1 spoon
- **Fresh air** (5min outside) → +1 spoon
- **Social connection** (text/call) → +1 spoon
- **Stim/sensory break** → +1 spoon

Click any booster when you do it - it adds to your daily capacity but can only be used once per day.

## Quick Start: Adding Your First Task

### Method 1: Quick Add (Fastest)

1. **Click "+ Add Task"** to expand the section
2. Choose energy level:
   - **Red button** = Low Energy task (1 spoon)
   - **Yellow button** = Medium Energy task (2 spoons)
   - **Green button** = High Energy task (3 spoons)
3. **Enter task name** in the prompt
4. **(Optional)** Enter client name
5. **(Optional)** Mark as billable
6. **Select time estimate** from the modal:
   - 15 min / 30 min / 1 hour / 2 hours / Custom
7. **Task appears in "Later" tab** by default

### Method 2: Advanced Add Task (Full Control)

1. **Click "+ Add Task"** to expand
2. **Click "⚙️ Advanced Add Task (with all metadata)"** button
3. **Fill out the form:**
   - **Task Title*** (required)
   - **Category** (e.g., Work, Personal, Admin)
   - **Energy Level** (Low/Medium/High)
   - **Urgency** (Critical/Important/Normal/Low)
   - **Focus Level** (affects spoon cost!)
     - High Focus = 1.5x spoons
     - Medium Focus = 1x spoons
     - Low Focus = 0.75x spoons
   - **Client** (optional)
   - **Billable** checkbox
   - **Due Date** (auto-sets timeframe!)
   - **Timeframe** (can override auto-placement)
   - **Waiting For** (track dependencies)
   - **Time Estimate** (in hours)
4. **Click "Add Task"**

- **📅 This Week** - This week's tasks
- **📆 Next Week** - Next week's tasks
- **🗓️ This Month** - This month's tasks
- **🌊 Later** - Someday/maybe tasks

**Tip:** Due dates automatically place tasks in the correct view!

### Task Card Information

Each task shows:

- **Title** (click to edit)
- **🥄 Spoon cost** (click to edit)
- **⏱ Time estimate** (if set)
- **Client name** (click to edit)
- **💰 Billable / Non-billable** (click to toggle)
- **📁 Category** (click to edit)
- **Urgency dropdown** (⚪ Normal, 🔴 Important, ⚠️ Critical, 🔵 Low)
- **Focus Level dropdown** (🧠 Low, 🧠🧠 Med, 🧠🧠🧠 High)
- **⏸️ Waiting For** badge (if set, click to edit)
- **📆 Due Date** badge (if set, click to edit with calendar)
- **Timeframe dropdown** (move between views)
- **Break Down button** (AI breaks task into subtasks)
- **Complete button** (green)
- **Delete button** (red)

### Editing Tasks

**Everything is editable!** Just click on the field:

- **Title** → Click text, enter new title
- **Spoons** → Click 🥄 badge, enter new number
- **Client** → Click client name, enter new client
- **Billable** → Click badge to toggle
- **Category** → Click 📁 badge, enter new category
- **Urgency** → Click dropdown, select level
- **Focus Level** → Click dropdown (auto-recalculates spoons!)
- **Waiting For** → Click ⏸️ badge, enter dependency
- **Due Date** → Click 📆 badge, calendar picker opens

### Moving Tasks Between Views

Use the **timeframe dropdown** on each task:
- Select: Today / This Week / Next Week / This Month / Later
- Task moves immediately

**Or:** Set a due date and it auto-moves to the correct view!

### Breaking Down Tasks

For complex tasks:

1. **Click "Break Down"** button
2. AI analyzes the task and suggests 3-5 subtasks
3. **Review the suggestions**
4. **Click "Use These Subtasks"**
5. Task becomes expandable (▶ icon)
6. Click to expand/collapse subtasks

**Subtasks:**
- Can be completed individually
- Each has its own spoon/time cost
- Parent task completes when all subtasks done

### Completing Tasks

1. **Click the green "Complete" button**
2. **Completion modal appears** showing:
   - How you feel about completing it
   - Actual time taken (optional)
3. **Select feeling** or click outside to skip
4. **Task moves to completed list**

**Important:** If task costs more spoons than you have remaining, the **Override Safety System** activates (see next section).

## Override Safety System

**Purpose:** Prevents burnout by forcing accountability before you overcommit.

### When Override System Activates

When you try to complete a task that costs **more spoons than you have remaining**.

**Example:**
- You have 2 spoons left
- Task costs 3 spoons
- Override modal appears

### Override Modal

Shows:
- **Task name and cost**
- **Your remaining spoons**
- **Debt you'll incur** (e.g., -1 spoons)
- **Accountability checkbox:** "I texted Holly or Toni"
- **Reason field** (min 10 characters)
- **Override count this week** (X/5)

### To Complete Override:

1. **Text your accountability person** (Holly or Toni) saying:
   - "Overriding [task name] - going into spoon debt"
2. **Check the box** confirming you texted
3. **Enter reason** (minimum 10 characters explaining urgency)
4. **Click "Override & Complete"**

### What Happens After Override:

- Task completes
- You go into **spoon debt** (e.g., -1 spoons shows at top)
- Debt carries to tomorrow: **Tomorrow's capacity = normal capacity - debt**
- Override logged with date, task, reason, debt amount

**Example:**
- Today: Complete 3-spoon task with 2 spoons → -1 debt
- Tomorrow: Would normally have 5 spoons → Start with 4 spoons

### Weekly Override Limit: 5 Per Week

After your **5th override in one week**, the system blocks further overrides.

**Weekly Limit Modal appears** with 3 options:

1. **Switch to Crisis Mode**
   - Removes all spoon limits temporarily
   - Tracks everything you complete in crisis
   - Auto-exits tomorrow at 8 AM

2. **Defer Task to Next Week**
   - Moves task to "Next Week" view
   - Doesn't use override

3. **Contact Holly for Check-in**
   - Opens SMS to Holly
   - Doesn't complete task

### Pattern Alerts

#### 48-Hour Alert (2 days in spoon debt)

**Yellow banner appears:**
- "You've been in spoon debt for 2 days in a row"
- Shows common causes: overcommitting, underestimating, no recovery time
- Action buttons:
  - Schedule check-in with Holly (SMS)
  - Review this week's overrides
  - Remind me tomorrow

#### 5-Day Burnout Alert (5 consecutive days in debt)

**RED BANNER appears:**
- "You've been in spoon debt for 5 days - YOU WILL CRASH"
- Tomorrow auto-suggests **RECOVERY DAY**
- **Cannot dismiss without taking action:**
  1. Clear my calendar tomorrow
  2. Talk to Holly about what's happening
  3. Acknowledge I'm heading for shutdown

**This is the critical intervention point** - system forces a pause.

## Crisis Mode

**Emergency escape hatch for true crises.**

### What Crisis Mode Does:

- ✅ **Removes all spoon limits** temporarily
- ✅ **No override modals** when completing tasks
- ✅ **Tracks everything** you complete in crisis
- ✅ **Shows big red banner:** "SPOON OVERRIDE MODE ACTIVE"
- ✅ **Auto-exits** tomorrow at 8:00 AM
- ⚠️ **Still accumulates spoon debt** (you'll see it when crisis mode ends)

### When to Use Crisis Mode:

**Use for:**
- True emergencies (urgent deadline, family crisis, etc.)
- When override system is blocking urgent work
- Client emergency that can't wait

**Don't use for:**
- Regular work that just feels urgent
- Avoiding accountability
- Every week (defeats the purpose)

### How to Activate Crisis Mode:

**Method 1: From Weekly Limit Modal**
- Hit 5 overrides → Click "Switch to Crisis Mode"

**Method 2: Manual Activation**
1. Click **"Activate Override Mode"** button in header
2. **Crisis Mode Confirmation Modal** appears
3. **Enter reason** (min 10 characters explaining the crisis)
4. **Click "Activate Crisis Mode"**

### While in Crisis Mode:

- Red banner at top: "🚨 SPOON OVERRIDE MODE ACTIVE"
- Complete tasks without limit prompts
- Focus on getting through the crisis
- All debt accumulates silently

### Exiting Crisis Mode:

**Automatic:** Tomorrow at 8:00 AM
- Crisis mode deactivates
- Shows accumulated spoon debt
- Normal limits resume

**Manual:** Click "Exit Override Mode" button in banner
- Immediately exits
- Shows total debt incurred

### After Crisis Mode:

- You'll see total spoon debt accumulated
- This debt carries to next day
- Pattern alerts may trigger if multiple days in debt
- System helps you recover

## Advanced Task Features

### Focus Level & Spoon Calculation

**Focus Level multiplies base spoon cost:**

- **🧠 Low Focus** (0.75x) - Can multitask, low concentration needed
  - Example: 2 base spoons → 2 × 0.75 = **1.5 spoons**

- **🧠🧠 Medium Focus** (1.0x) - Standard concentration
  - Example: 2 base spoons → 2 × 1.0 = **2 spoons**

- **🧠🧠🧠 High Focus** (1.5x) - Deep work, no interruptions
  - Example: 2 base spoons → 2 × 1.5 = **3 spoons**

**Changing focus level auto-recalculates spoons!**

### Urgency & Prioritization

**Urgency affects task sorting in Crisis Mode:**

- **⚠️ Critical** - Do ASAP, life/death/career impact
- **🔴 Important** - Should do soon, significant impact
- **⚪ Normal** - Standard priority
- **🔵 Low** - Nice to have, can wait

**In Crisis Mode:** Tasks automatically sort by urgency (Critical first).

### Due Dates & Auto-Timeframes

**Setting a due date automatically places the task:**

- **Today or overdue** → 🔥 Today tab
- **Within 7 days** → 📅 This Week tab
- **Within 14 days** → 📆 Next Week tab
- **Within 30 days** → 🗓️ This Month tab
- **Beyond 30 days** → 🌊 Later tab

**To edit due date:**
1. Click the 📆 badge on task
2. Calendar picker modal opens
3. Select new date (or clear date)
4. Task auto-moves to correct view

### Waiting For (Dependency Tracking)

**Use when task is blocked:**

- Waiting for: "API team response"
- Waiting for: "Client approval"
- Waiting for: "Budget confirmation"

**Shows as yellow ⏸️ badge** - click to edit

**In Crisis Mode:** AI can suggest skipping tasks that are waiting on others.

### Time Estimates

**Two ways to set:**

1. **Quick Add:** Modal asks for time (15min, 30min, 1hr, 2hr, custom)
2. **Advanced Add:** Time Estimate field in form

**Time tracking helps with:**
- Daily capacity warnings ("You have 8.5h of tasks but only 8h available")
- Billing for client work
- Understanding your actual pace

**Time vs. Spoons:**
- **Time** = Clock hours to complete
- **Spoons** = Mental/emotional energy cost
- A 15-minute task can cost 3 spoons (high stress call)
- A 2-hour task can cost 1 spoon (enjoyable creative work)

## Time & Capacity Management

### Daily Capacity Check (Today View)

When viewing **Today** tab, you'll see a capacity card showing:

**Calendar Time:**
- Hours in meetings/calls (if you entered calendar time)
- Available hours for task work (8hr workday - calendar time)

**Task Time:**
- Total estimated time for all Today tasks
- Compares to available hours

**Warning Levels:**

🔵 **Good Balance** (under 4 hours of tasks):
- "Good balance - 3.5h of tasks with 6h available"

🟡 **Might Be Overcommitted** (tasks > available time):
- "You might be overcommitted - 9h of tasks with only 6h available"

🔴 **Seriously Overcommitted** (tasks > entire workday):
- "Seriously overcommitted! You have 12h of tasks but only 8h available"
- Suggests moving tasks to This Week or Later

### Calendar Input

At top of Today view:

1. **Enter meetings/calls** in format:
   - "2h" = 2 hours of meetings
   - "1.5h" or "90m" = 1.5 hours
   - "30m" = 30 minutes

2. System calculates:
   - Available hours = 8hr workday - meeting time
   - Compares to total task time

**Example:**
- Workday: 8 hours
- Meetings: 2 hours
- Available: 6 hours
- Tasks: 7 hours
- **Warning:** "You might be overcommitted"

### Spoon Debt Display

**When in debt, you'll see at top:**

"⚠️ Starting today with **-3 spoon debt**"

**What this means:**
- You went into debt yesterday
- Today's capacity is reduced by debt amount
- Example: Normal 5 spoons - 3 debt = **Start with 2 spoons**

**Debt clears when:**
- You complete a day without overriding
- You stay within your capacity

## Keyboard Shortcuts & Tips

### Quick Tips

**Speed up task entry:**
- Use Quick Add buttons for routine tasks
- Save Advanced Add for complex/client work
- Set due dates to auto-organize tasks

**Manage energy wisely:**
- Do high-focus tasks when you have most spoons
- Save low-focus tasks for end of day
- Use Quick Boosters strategically (before hard tasks)

**Prevent burnout:**
- Do honest Neuro-Checks every day
- Don't ignore the 48-hour warning
- When you hit 5-day alert, STOP
- Text Holly/Toni before overriding (don't just check the box)

**Crisis Mode guidelines:**
- Only use for true crises
- Set a timer for how long you'll be in crisis mode
- Plan recovery time after crisis ends
- Review what caused the crisis to prevent next time

### Brain Mode Tips

**ADHD Mode chosen?**
- Break tasks down into smaller chunks
- Switch between tasks if stuck
- Use Quick Boosters frequently
- Set more ambitious goals (you might surprise yourself)

**Autism Mode chosen?**
- Stick to routine task order
- Avoid switching tasks mid-flow
- Be conservative with estimates
- Protect your schedule from interruptions

**Balanced Mode?**
- Mix of strategies
- Check in with yourself mid-day
- Adjust approach as needed

## Troubleshooting

### "I can't complete a task - it says I don't have enough spoons"

**This is the Override Safety System working!**

**Options:**
1. **Override with accountability** - Text Holly/Toni, enter reason, complete task
2. **Defer the task** - Move to tomorrow or This Week
3. **Break it down** - Use Break Down feature to do part of it
4. **Switch to Crisis Mode** - If this is truly urgent

**Remember:** The system is protecting you from burnout. 5 overrides per week is the limit for a reason.

### "I did my Neuro-Check but my spoons seem wrong"

**Spoon calculation considers:**
- Mood + Sleep + Energy (weighted average)
- Brain mode adjustments
- Number of burnout indicators checked (each reduces capacity)

**If you got fewer spoons than expected:**
- Check how many burnout indicators you selected (each costs spoons)
- Your mood/sleep/energy scores might be lower than you thought
- This might be your body telling you to slow down

**To adjust:**
- You can click the 🥄 badge on individual tasks to manually change spoon cost
- Use Quick Boosters to add capacity
- Consider if your body knows something your brain doesn't want to admit

### "Time estimates are wrong (showing minutes as hours or vice versa)"

**This was a bug that's been fixed!** Pull the latest code.

**If still seeing issues:**
- Quick Add time estimates should show correctly (1h, 2h, etc.)
- Advanced Add uses hours input, converts to display correctly
- Refresh your browser with hard refresh (Ctrl+Shift+R or Cmd+Shift+R)

### "Dates are off by one day"

**This was a timezone bug that's been fixed!** Pull the latest code.

**Selecting today's date should show today** - not yesterday or tomorrow.

If still seeing issues:
- Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)
- Clear browser cache
- Make sure you pulled latest code

### "I'm in Crisis Mode and can't get out"

**Crisis Mode auto-exits at 8 AM tomorrow.**

**To exit manually:**
1. Look for red banner at top: "SPOON OVERRIDE MODE ACTIVE"
2. Click "Exit Override Mode" button in banner
3. You'll see accumulated debt
4. Normal limits resume

**If button doesn't work:**
- Refresh browser
- Worst case: Check localStorage and delete 'ccCrisisMode' key

### "I want to see my override history"

**Override log is stored in localStorage** as 'ccOverrideLog'

**To view:**
1. Open browser console (F12)
2. Type: `JSON.parse(localStorage.getItem('ccOverrideLog'))`
3. See all overrides with dates, tasks, reasons, debt amounts

**Can also:**
- Review when 48-hour alert appears (has "Review overrides" button)
- Export your data (includes override log)

### "Tasks disappeared / Data lost"

**Check completed tasks:**
- Tasks you complete don't disappear - they're in the completed list
- View by clicking "View Completed" or in billing view

**If actually lost:**
1. Check if localStorage was cleared (browser issue)
2. Look for backup file (app auto-backs up corrupted data)
3. Check your Export Data backups (if you made any)

**Prevention:**
- Export data regularly (weekly or monthly)
- Don't clear browser data without exporting first
- Consider running app in Replit or hosting it (persistent)

### "App won't load / Shows purple background only"

**This is a JavaScript error:**

1. **Open browser console** (F12)
2. **Look for error message**
3. **Common causes:**
   - Babel transpilation error (syntax error in code)
   - React rendering error
   - Missing dependency

**Fix:**
- Refresh browser (Ctrl+R)
- Hard refresh (Ctrl+Shift+R)
- Clear cache and refresh
- Pull latest code from repo
- Check browser console for specific error
