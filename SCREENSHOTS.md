## 📸 Screenshot Best Practices

### Technical Settings
- **Resolution**: 1920x1080 minimum for desktop views
- **Mobile**: 375x812 (iPhone X size) for mobile views
- **Format**: PNG (for crisp UI elements)
- **Color**: Full color, no filters

### Content Guidelines
- **Use realistic data**: Don't show "Test Task 1", "Test Task 2"
  - Good: "Record client demo video"
  - Bad: "asdfasdf"
- **Show representative states**: Not all tasks Critical urgency
- **Include variety**: Different energy levels, categories, clients
- **Avoid sensitive data**: No real client names if private

### Annotation Guidelines (Optional)
- Use red arrows or boxes to highlight key features
- Add text labels with clear, sans-serif font (Arial, Roboto)
- Keep annotations minimal - captions explain details
- Use consistent annotation style across all screenshots

### Context
- **Show full context**: Include spoon capacity at top, timeframe tabs
- **Avoid cropping critical UI**: User should see entire feature
- **Multiple states**: Capture before/after for dynamic features

   - Neuro-Check → Add task → Complete task → Override modal

3. **Calendar picker** (10 seconds):
   - Click due date badge → Calendar opens → Select date → Task moves to new timeframe

4. **Task breakdown** (20 seconds):
   - Complex task → Click Break Down → AI suggests subtasks → Add one → Appears in list

5. **Crisis mode** (25 seconds):
   - Enter Crisis Mode → Complete tasks without overrides → Exit Crisis Mode
